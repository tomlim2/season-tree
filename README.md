# 계절나무

잎 수천 장으로 그린 나무 한 그루. 계절을 바꾸면 화면 한쪽 끝에서 다른 쪽으로 색이 쓸려 가며 잎이 한 장씩 갈아입고, 모양을 바꾸면 땅에서부터 새로 돋아나고, 바람이 불면 가지가 휘고 잎 몇 장이 왼쪽으로 날려 가 땅에 내려앉았다가 사라진다.
three.js의 TSL(Three.js Shading Language)로 쓴 실시간 장면. WebGPU가 있는 브라우저에서는 WebGPU로, 없으면 WebGL 2로 그린다 (셰이더 한 벌로). 에셋 없음.

https://tomlim2.github.io/season-tree/

```bash
npm install
npm run dev
```

- 위의 다섯 동그라미: 계절 (벚꽃·여름·가을·겨울·밤). 숫자 키 1~5 로도
- 왼쪽의 다섯 모양: 둥근 나무·침엽수·기둥 나무·수양버들·덤불
- 아래 "새 나무" 또는 스페이스: 같은 모양으로 다시 자란다
- 끌면 나무 둘레를 돈다. `?gl=1` 은 WebGL 2 강제

구조와 그리는 방법은 [MAP.md](MAP.md).

## 참고

X 에 올라온 20초짜리 녹화 영상 한 편(잎 카드로 그린 나무 생성기: 계절 버튼, 모양 버튼, 바람에 날리는 잎, 사선으로 쓸리는 배경 전환)을 보고 같은 느낌을 처음부터 다시 만들어 본 연습작이다. 나무를 키우는 법, 잎을 놓는 법, 색, 글씨는 전부 새로 만들었다.
